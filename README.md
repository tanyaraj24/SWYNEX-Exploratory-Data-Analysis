# SWYNEX-Exploratory-Data-Analysis
Task-2 Exploratory Data Analysis of Cafe Sales Transactions using Microsoft Excel

### Overview
Performed Exploratory Data Analysis (EDA) on 10,000 cafe sales transactions using Microsoft Excel to understand sales performance, item-wise revenue, transaction patterns, payment methods, order locations, and monthly revenue trends.

### Analysis Performed
- Calculated key business metrics including total transactions, total revenue, average transaction value, average quantity per transaction, average price per unit, and minimum and maximum transaction values.
- Analyzed transaction counts, quantities sold, and revenue for eight different items.
- Compared transaction counts across payment methods and order locations.
- Evaluated missing information in payment methods, locations, and transaction dates.
- Analyzed monthly revenue trends using summary tables and charts.

### Key Insights
- Salad generated the highest revenue among the eight items at 19,170.
- June recorded the highest monthly revenue at 7,359, while February recorded the lowest at 6,652.
- Payment method information was missing in 3,178 transactions.
- Location information was missing in 3,961 transactions.
- Coffee had the highest transaction count, while Tea had the lowest among the eight items.

### Tools Used
- Microsoft Excel
- Excel formulas and functions
- PivotTables
- Charts and data visualization

### Outcome
Created an EDA summary to evaluate overall sales performance, compare product-level results, identify revenue trends, and highlight data limitations that may affect business analysis.
